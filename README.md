# Shiyang Zhou

Personal academic homepage: **https://clausy9.github.io/**

Research in video generation, world models, and world action models.

## Local preview

```sh
python3 -m http.server 4180 --bind 127.0.0.1
```

Open http://127.0.0.1:4180/. The site uses static HTML, CSS, and JavaScript, with no build dependencies.

## Edit the website

- `index.html`: biography, experience, publications, awards, and education.
- `style.css`: desktop and mobile layouts, including the portrait framing.
- `script.js`: demo player dialog and section navigation.
- `assets/`: locally hosted images, fonts, and demo video.

GitHub Pages publishes the root of the `main` branch. `.nojekyll` serves the files directly.
